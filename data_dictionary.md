# CSA-CPAP-Prescribing Data Dictionary
This dictionary documents the expected private `coded_output.xlsx` workbook variables, Stata-derived analysis variables, and generated output artifacts for the CSA-CPAP-Prescribing workflow. It contains no row-level clinical data.
## Source And Privacy Notes
- Source input: authorized local `coded_output.xlsx`, read from sheet `Sheet1` by `Stata/CSA regressions.do`.
- Raw EHR/sleep-center data and derived row-level `.dta` files are restricted and must not be committed.
- Rows marked `needs_review` reflect fields inferred from legacy variable names or Stata labels rather than a separate source codebook.
